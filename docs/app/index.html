Self-Hosted Docker Gateway

                
Deploy your own zero-trust JSR1 protocol bridge in seconds. Browsers authenticate via 60s single-use WebSocket tickets while raw RDP, VNC, SSH, and SFTP stay inside your private network.

  -e JALADESK_GATEWAY_CORS_ORIGINS=https://ribato22.github.io \
  -e JALADESK_GATEWAY_DEMO=1 \
